# NAPCO Static Website — review build v0.1

Prepared 2 November 2026. **A working, 21-page static review build, not a live-site deployment or a full migration of the existing website.**

The selected first combined homepage is implemented as responsive HTML, CSS and small progressive JavaScript enhancements. The original NAPCO logo and focus device are separate image assets. No CMS, WordPress plugin, database, external font service or third-party JavaScript dependency is required.

## What is included

The homepage retains the tall architectural hero; three solution cards; expertise strip; technical-thinking banner; complex-assemblies band; industry cards; material/process sections; technical resources; Insights; enquiry CTA; and footer. It is not a screenshot used as a website.

Twenty-one pages cover the homepage, product families, construction and selected industrial applications, company, innovation, technical resources, Insights, contact, quote preparation and search. See `docs/build-manifest.json` for the exact route inventory. Included pages preserve their corresponding existing NAPCO paths where applicable. Other existing pages, store operations, documents and legal content have **not** been migrated.

## Run locally

Use Node.js 22 or later. No dependencies need to be installed.

```sh
npm run build
npm run preview
```

Open `http://127.0.0.1:8080`. Stop the server with Ctrl+C. Opening `dist/index.html` by double-click is not equivalent: site links and assets use root-relative paths and need an HTTP server.

```sh
npm test
```

The test rebuilds and checks local page links, local images, anchors, metadata, image attributes and preview indexing flags.

## Review protection

Preview mode emits `noindex,nofollow,noarchive` metadata, a disallowing robots.txt and a Pages `X-Robots-Tag` header. These are indexing instructions, **not authentication or privacy protection**. The preview still needs access control if it must be confidential.

Production mode is intentionally gated behind `SITE_MODE=production`, an HTTPS `SITE_URL`, and `LAUNCH_APPROVED=true`. These are engineering safeguards, not a substitute for explicit approval. Do not enable them in this phase. The supplied build should not replace the live site or store.

## Enquiries and existing operations

The contact/quote interface validates inputs and prepares a draft in the visitor's email app. It **does not send or store email on a server**. The page explicitly states this and also links to the existing NAPCO contact/quote pages. Server-side delivery, spam protection and delivery testing remain a later setup task.

Store links continue to point to the existing NAPCO store. No products, checkout settings, stock, scheduled posts, live pages or DNS were modified. Social publishing remains a separate workflow.

## Before public launch

Review and approve all copy. Import the approved current articles. Replace low-resolution photographic crops, particularly the coatings image and archive thumbnail, with clean masters. Verify the actual font family and its licence: this build uses a system Arial/sans-serif fallback, not a newly approved brand font. Verify document links, legal pages, forms, hosted headers, mobile crops and performance on the real review deployment. Plan existing-route coverage and store coexistence before any domain switch.

The supplied conceptual imagery is not evidence of real NAPCO projects, factories, staff, tests or validated installations. Image provenance is recorded in `public/assets/asset-manifest.json`.

A future WordPress implementation can use this approved structure, copy and assets as its specification. This package is not a WordPress theme and does not claim an automatic conversion path.
