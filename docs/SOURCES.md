## Deliberately not carried forward

Dated “33 years” wording, unverified leadership claims, guaranteed results, universal suitability, environmental claims, named customer associations and certification/test claims are not introduced into this review. New copy starts with the application and routes to technical discussion.

## Technical uncertainties

Public page content was readable. Runtime CSS/font licensing and the existing WordPress theme, plugins and hosting stack were not verified for this static build. The independent Node static generator is a proposed implementation, not an assertion about the existing stack. System Arial is provisional.
